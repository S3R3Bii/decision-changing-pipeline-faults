# Exact public aggregate fixture

Consumer Financial Protection Bureau, [Consumer Complaint Database](https://www.consumerfinance.gov/data-research/consumer-complaints/). Original monthly API queries, retrieval timestamps and hashes are preserved in each of102 aggregate snapshot files. Coverage is January2018–June2026; selected categories are present in every month. Source taxonomy changes outside those categories are retained and accounted for rather than silently normalized into new labels.

The fixture is the reviewed public subset from [complaint-capacity-forecasting at888c9d8](https://github.com/S3R3Bii/complaint-capacity-forecasting/tree/888c9d819cec605b3839e223bad7492846a00fa0/data). Its [whole-period reconciliation](https://github.com/S3R3Bii/complaint-capacity-forecasting/blob/888c9d819cec605b3839e223bad7492846a00fa0/results/source_reconciliation.json) checks disjoint monthly counts against a separate official whole-period query and verifies inclusive API date boundaries. This study reuses those exact public source files and attribution, not its forecasts, trained models, study conclusions or private manuscript.

The CFPB [website privacy/use policy](https://www.consumerfinance.gov/privacy/website-privacy-policy/) describes generally public-domain CFPB-created website material and retained third-party rights. These files contain factual aggregate counts, not consumer-submitted narratives or individual records. No endorsement is implied and no additional blanket license is asserted over source data. Public code and derived fault scenarios are this project's work; manuscript drafts remain private.

Complaint reporting can be delayed and current historical counts can be revised. The source snapshot does not reconstruct original publication vintages or known real pipeline incidents. Every fault in the experiment is explicitly injected, and the reserve policy is a controlled decision proxy.

Related implementation context: [Deequ's official project](https://github.com/awslabs/deequ) shows how declared constraints can check tabular data before downstream use. This study implements and measures its own small declared check sets. It is not a Deequ product benchmark and does not imply that richer constraints cannot detect these faults. The contribution is a decision-change-weighted comparison under a review budget, without an exhaustive novelty claim.
